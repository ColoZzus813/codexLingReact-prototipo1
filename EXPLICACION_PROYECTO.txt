CodexLing: Aplicación educativa de programación

Qué es CodexLing
CodexLing es una plataforma web creada para aprender programación y administrar cursos de forma dinámica. La aplicación está construida con React en el frontend y Node.js + Express en el backend, lo que le permite tener una interfaz moderna y una API que envía y recibe datos.

Composición del proyecto
1. Frontend (React)
   - Carpeta `src/`: contiene los componentes, páginas y estilos.
   - `src/App.jsx`: es el componente principal que controla qué página se muestra, el menú, la búsqueda y el fondo visual.
   - `src/assets/components/`: guarda piezas reutilizables como `Header`, `MobileMenu`, `Marquee` y `CourseCard`.
   - `src/assets/pages/`: contiene las páginas del sitio: `Home`, `Html`, `Python`, `Java`, `Php`, `PythonCourse`, `Admin`.
   - `src/styles/Global.css`: define la estética general, efectos visuales y la sensación de la aplicación.

2. Backend (API REST)
   - Carpeta `server/`: alberga la lógica del servidor.
   - `server/app.js`: configura Express, routes, middlewares y el manejo de errores.
   - `server/index.js`: arranca la aplicación y conecta con la base de datos.
   - `server/controllers/`: implementa la lógica de cada recurso (cursos, usuarios, lecciones, administrador).
   - `server/routes/`: define los endpoints de la API.
   - `server/models/`: administra el acceso a datos y la persistencia.
   - `server/config/`: tiene la configuración de entorno y la conexión a SQL Server.

3. Datos y base de datos
   - Se utiliza SQL Server como base de datos para guardar cursos, usuarios, lecciones y niveles.
   - La información puede cargarse desde archivos de datos en `server/data/` y mantiene la aplicación lista para usar con un repositorio centralizado.

Cómo está hecho visualmente
- El fondo tiene un degradado oscuro con tonos morados, cian y ámbar, creando un estilo tecnológico y moderno.
- Hay un patrón de líneas y una cuadrícula suave en el fondo que da sensación de movimiento sin distraer.
- El logo se muestra como una marca de agua tenue en el centro de la pantalla para reforzar la identidad visual.
- El header es translúcido y usa blur, lo que permite que la interfaz se vea profesional y tecnológica.
- Los botones e iconos tienen animaciones suaves al pasar el cursor: cambian de color y escalan ligeramente.

Estructura visual clave
- `Header`: incluye el logo, la búsqueda, los accesos rápidos y el menú de usuario.
- `MobileMenu`: ofrece navegación adaptada a pantallas pequeñas.
- `Marquee`: agrega un mensaje o animación en la parte superior para dar dinamismo.
- `CourseCard`: tarjeta de cada curso con icono, título y descripción breve.

Cómo interactúa el usuario
1. Al abrir la app, se ve la pantalla de inicio con las tarjetas de cursos.
2. El `Home` carga los cursos desde la API y filtra según lo que el usuario busca.
3. Al elegir un curso, la app cambia de página sin recargar gracias al enrutado interno de React.
4. El usuario puede registrarse e iniciar sesión directamente desde el header.
5. Si el usuario es administrador, puede acceder a opciones avanzadas como crear, editar o eliminar contenido.

Detalles de la parte de administración
- La página `Admin` permite gestionar cursos, usuarios, lecciones y niveles.
- También se puede crear lecciones de Python con validación automática.
- La administración usa `adminKey` para activar los permisos y proteger las operaciones.
- Los cambios se guardan en la base de datos y se reflejan en la interfaz de forma inmediata.

Experiencia visual y de uso
- La app combina el estilo oscuro con elementos brillantes para lograr un aspecto moderno y tecnológico.
- Los textos claros sobre fondo oscuro facilitan la lectura.
- Los cursos se presentan en tarjetas llamativas, cada una con un icono y color asociados al lenguaje.
- El diseño es responsive y se adapta a pantallas más pequeñas gracias al menú móvil.

Por qué es buena para exponer en una feria
- Muestra una aplicación completa con frontend y backend.
- Tiene una interfaz clara, atractiva y profesional.
- Incluye funcionalidades reales: registro, login, búsqueda, navegación entre cursos, administración y validación de código.
- Permite explicar conceptos como API REST, base de datos, componentes reutilizables y visualización de datos.

Cómo exponer el proyecto
- Comienza mostrando la portada visual y las tarjetas de cursos.
- Explica la lógica de la aplicación: React en el cliente y API en el servidor.
- Muestra cómo se usa la búsqueda y cómo se navega entre cursos.
- Si puedes, demuestra el panel administrativo con un cambio en un curso.
- Finalmente, comenta la validación de Python como ejemplo de integración entre frontend, backend y servicios externos.

Resumen ampliado
CodexLing es una plataforma educativa que combina una experiencia visual cuidada con una arquitectura técnica sólida. Su diseño moderno y sus funcionalidades interactivas la hacen ideal para presentar en una feria de proyectos, porque es fácil de entender y muestra múltiples tecnologías trabajando juntas.
